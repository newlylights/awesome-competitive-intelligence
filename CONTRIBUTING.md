# Contributing to awesome-competitive-intelligence 🎯

Thanks for contributing! This is a community-curated list of competitive intelligence resources.

## How to Contribute

### Adding Resources

1. **Fork** this repository
2. **Create a branch**: `git checkout -b add-resource-name`
3. **Add your resource** to the appropriate section in `README.md` or create a new `.md` file for frameworks/templates
4. **Follow the format**: `[Resource Name](URL) — Brief description of what it is and why it's valuable`
5. **Submit a pull request**

### Resource Guidelines

- Must be directly relevant to competitive intelligence, market analysis, or competitor research
- Prefer tools and resources that are actively maintained
- Open source resources are preferred, but commercial tools are welcome if they're widely used
- No affiliate links or promotional-only content
- One resource per PR for easier review

### Template Contributions

If you're submitting a template or framework:

- Follow the existing patterns in `battle-card-template.md` or `competitor-analysis-template.md`
- Include practical, fillable sections (not just theory)
- Add links to related resources within the repo
- Include data sources / references where applicable

## Quality Standards

We aim for resources that are:

- **Actionable** — Not just theory, but templates and frameworks teams can use immediately
- **Current** — Updated within the last 2 years, or evergreen content
- **Credible** — From recognized sources, practitioners, or companies with proven track records
- **Structured** — Well-organized, easy to navigate and reference

## Code of Conduct

- Be respectful and constructive in discussions
- Focus on the resource quality, not the person
- Disclose any affiliation with resources you're adding

## Questions?

Open an issue for discussion before submitting a PR if you're unsure about fit.
